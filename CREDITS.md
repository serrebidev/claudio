# Credits

Claudio is a fork of [ctoth/claudio](https://github.com/ctoth/claudio). It is a hook-driven audio layer for coding agents: it listens to hook events from Claude Code, OpenAI Codex CLI, Gemini CLI, Qwen Code, and GitHub Copilot CLI, and plays a contextual sound without making the agent wait for playback.

The upstream project owns the original design and formats. This fork keeps that, and adds its own sounds and event coverage.

Questions and bug reports are welcome in the [SerrebiProjects Telegram group](https://t.me/SerrebiProjects). More serrebi projects: [projects.serrebiradio.com](https://projects.serrebiradio.com).
